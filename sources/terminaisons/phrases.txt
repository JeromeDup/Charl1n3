# ============================================================
# BIBLIOTHEQUE DE PHRASES - NIVEAU 1
# ============================================================
#
# CATEGORIE : PRES3
# Présent de l'indicatif - 3e personne du singulier et du pluriel
#
# REGLES D'ANNOTATION
#
# & ... &
#   Délimite le sujet de la phrase.
#   Exemple : &Les petits chats& *mangent dans le jardin.
#
# *
#   Placé immédiatement avant un verbe conjugué.
#   Exemple : *mang/ent
#
# /
#   Indique le début de la terminaison à travailler.
#
#   VERBES :
#     Placer / avant la terminaison verbale.
#     Exemple : *mang/e ou *mang/ent
#
#   ADJECTIFS :
#     Placer / avant la lettre ou les lettres muettes.
#     Exemples : peti/t, petit/e, petit/s
#
#   NOMS :
#     Si la consonne finale muette peut être retrouvée
#     grâce à un mot de la même famille, placer / avant.
#     Exemple : cha/t (chaton).
#
#     Pour une marque grammaticale ajoutée après cette
#     consonne, placer / avant la marque.
#     Exemple : chat/s
#
#   TERMINAISON VIDE :
#     Placer / à la fin du mot.
#     Exemple : chaton/
#     Cela signifie qu'aucune lettre ne doit être ajoutée.
#
# Les annotations peuvent se cumuler.
# Toutes les terminaisons annotées ne sont pas forcément
# demandées dans un même exercice.
#
# OBJECTIF :
# 3 à 5 phrases par exercice.
# 2 à 4 terminaisons potentielles par phrase.
# Environ 10 à 15 réponses par exercice.
#
# Pool composé majoritairement de situations réalistes,
# avec quelques phrases imaginaires ou humoristiques.
#
# ============================================================
